# Changelog

All notable public changes to Espasyo are documented here.

This project follows semantic versioning through Flutter's `version` field:
`MAJOR.MINOR.PATCH+BUILD`.

## [1.0.0+1] - 2026-05-04

### Added

- Public Android release foundation for Espasyo.
- Local-first seller, box, assignment, sales log, and seller balance records.
- Seller cash-out and manual deduction flows.
- Vacant box occupancy and reassignment workflows.
- Dashboard guide, splash screen, branding assets, and app icon.
- Local SQLite backup snapshots with Google Drive app-data backup and restore.
- Restore hardening for SQLite sidecar cleanup and database verification.
- Public README showcase and project documentation.
